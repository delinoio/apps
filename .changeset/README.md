# Pending changes

Follow the [changeset contract](../docs/repository-changeset-contract.md) to add,
validate and preview records. Records use Changesets Markdown with YAML frontmatter. Public notes use an
optional marked block separate from the internal summary. Release and record deletion are not implemented.

Before writing public text, follow the [public note authoring guide](../docs/repository-changeset-contract.md#public-note-authoring). It includes end-user examples and explains when to omit the public block.
