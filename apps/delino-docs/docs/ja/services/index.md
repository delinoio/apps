# サービス

- [Delcore](/ja/services/delcore/): 登録済みサービスからテナントの状態を確認します。
- [DevBase](/ja/services/devbase/): アプリケーションのエンドユーザーを管理します。
- [Git Tracker](/ja/services/git-tracker/): コミットの測定値とリグレッションを追跡します。
- [FixKey](/ja/services/fixkey/): 誤ったキーボード配列で入力された韓国語と英語の単語を修正します。
- [DeliTools](/ja/services/delitools/): API を通じてテキストを翻訳し、構造化データを抽出します。

ドキュメントサイトの概要については、[はじめに](/ja/guide/getting-started)をご覧ください。
