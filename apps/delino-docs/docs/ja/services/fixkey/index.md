# FixKey

FixKey は、誤ったキーボード配列で入力された単語を修正します。韓国語の2ボル式と米国英語の QWERTY による双方向の修正に対応しています。FixKey はデスクトップ上でローカルに動作し、アカウントは必要ありません。

## FixKey をインストールする

[FixKey のリリース](https://github.com/delinoio/apps/releases?q=fixkey%40)を開き、お使いのオペレーティングシステムとプロセッサに対応するパッケージを選択します。

- macOS ARM64：Apple シリコン用の DMG。FixKey を「アプリケーション」に移動して開きます。
- Windows x64 または ARM64：お使いのプロセッサ用の EXE インストーラー。Windows パッケージには Authenticode の発行元署名がないため、Windows に不明な発行元または SmartScreen の警告が表示される場合があります。
- Linux X11 x64 または ARM64：お使いのプロセッサ用の AppImage。Wayland はサポートされていません。

最低動作要件は、Apple シリコン搭載の macOS 11、WebView2 を搭載した Windows 10、または X11、GTK 3、WebKitGTK 4.1、AT-SPI アクセシビリティバスを備えた Linux です。これらはプラットフォームの前提条件です。すべてのアプリケーションやテキストフィールドとの互換性を保証するものではありません。

## 権限を付与する

FixKey が編集可能なフィールド内の現在の単語を読み取って置換するには、オペレーティングシステムのアクセシビリティ権限と入力権限が必要です。権限ダイアログの案内に従い、システム設定で要求されたアクセスを許可してから、**再確認**を選択してください。必要な権限と内蔵辞書の準備が整うまで、修正機能は無効のままです。パスワードフィールドと保護されたフィールドは対象外です。

macOS では、「システム設定」で**アクセシビリティ**と**入力監視**を確認します。アクセシビリティ権限によって、入力監視に個別の項目がなくても有効な入力アクセスが許可される場合があります。そのリストを確認するには、FixKey で**一般**を開き、**入力監視を設定**を選択します。FixKey がない場合は、システムの権限リストにある **+** を使用して、「アプリケーション」にある現在の FixKey.app を追加してから FixKey に戻り、再確認してください。macOS によって有効な入力アクセスがすでに許可されている場合、個別のリスト項目は必要ありません。

## 単語を修正する

デフォルトでは両方の配列が有効です。編集可能なフィールドに入力し、スペースまたは句読点で単語を終えます。FixKey は、有効になっている配列の候補を内蔵辞書と照合します。有効な言語のうち正確に1つだけが候補を認識し、その候補が元の単語と異なる場合にのみ、単語を置換します。どの言語も候補を認識しない場合や、複数の言語が候補を認識する場合、単語は変更されません。

たとえば、キー入力シーケンス `rPthrgo` と `zlqhemrk` は `계속해` と `키보드가` に変換できます。これらは配列修正の例です。結果は、現在のフィールド、入力コンテキスト、辞書による認識に左右されます。

FixKey は、修正された単語の後にある区切り文字を保持します。Enter と Tab では修正は実行されません。URL やメールアドレスで使用される句読点がある場合、FixKey がトークン全体を分類できるようになるまで評価が遅れることがあります。文字の間にあるアポストロフィとハイフンは単語の一部として保持されます。

自動修正では、貼り付けられたテキストやプログラムによって挿入されたテキスト、数字、絵文字、URL、メールアドレス、複数の文字体系が混在するトークンはスキップされます。韓国語入力の文字合成が完了するまで待機します。不明なフィールド、権限を利用できない場合、安全に変更できないフィールドには手を加えません。

macOS または Windows で自動修正が成功すると、FixKey は修正後の言語に対応する有効な入力ソースの選択も試みます。Windows では、個別の米国英語 QWERTY 入力ソースが有効になっていない場合も含め、Microsoft 韓国語 IME のハングルモードとラテン文字モードを使用できます。韓国語 IME は2ボル式に設定しておいてください。入力ソースを選択できない場合や選択に失敗した場合でも、修正されたテキストと直後の取り消し機能は引き続き利用できます。閉じている、またはサポートされていない Windows IME は変更されません。Linux では現在の入力ソースが維持されます。直後の取り消しを行っても、入力ソースが再度変更されることはありません。

### 修正を取り消す

自動修正の直後に Backspace キーを押すと、元の単語とその区切り文字が復元されます。さらに Backspace キーを押すと、通常どおり削除されます。キャレットの移動、選択範囲の変更、フィールドの切り替え、または別の単語の入力開始により、この直後の取り消しコンテキストは終了します。

### 候補を手動で選択する

1. **ショートカット**を開き、手動候補用のショートカットを割り当てます。デフォルトでは割り当てられていません。登録に失敗した場合は、表示された理由を確認するか、別のショートカットを選択してください。
2. 編集可能なフィールドに単語を入力し、ショートカットを使用します。
3. 矢印キーを使って候補を選択します。Enter キーを押すと適用され、Esc キーを押すと選択画面が閉じます。

選択画面には辞書による認識結果が表示されます。認識されていない候補を明示的に選択することもできます。入力元のキャレットを移動するかアプリケーションを切り替えると、選択画面が閉じます。FixKey が安全な置換対象を特定できない場合、選択画面は利用できません。

## 修正を設定する

**一般**では、修正の一時停止または再開、有効にする言語の選択、ログイン時の起動の有効化、インターフェイスの言語とテーマの選択を行えます。ログイン時の起動はデフォルトで無効です。設定はすぐに適用され、ローカルに保存されます。

アプリケーションを変更対象外にするには、**除外するアプリ**に追加します。除外対象は、表示名だけでなくアプリケーション自体によって識別されます。解決できないアプリケーションも、確認できるようリストに残ります。

## プライバシーとオフラインでの使用

FixKey はデバイス上で入力を処理します。入力テキスト、候補、文書の内容、ウィンドウタイトル、修正履歴を保存または送信することはありません。置換にクリップボードは使用しません。テレメトリ、リモートでのクラッシュレポート、自動的な診断情報のアップロードはありません。

辞書が内蔵されているため、権限の準備が整えば初回起動時からオフラインで修正できます。辞書はアプリケーションのアップデートに伴って変更されます。辞書を個別にダウンロードする機能や、ユーザー辞書エディターはありません。ネットワークの使用は、アップデートの確認とダウンロードに限定されます。

## FixKey をアップデートする

FixKey は、起動時、実行中は24時間ごと、または**アップデート**で確認を要求したときに、安定版のアップデートを確認します。ダウンロードとインストールには同意が必要です。アップデートのペイロード署名が検証され、署名が無効な場合はインストールされません。インストール前に修正機能は停止し、設定は保持されます。

確認に失敗した場合は、手動で再試行するか、次回の定期確認を待ってください。インストールに失敗した場合は、FixKey を再起動するか、FixKey のリリースから適切なパッケージを再インストールしてください。以前のリリースを手動で再インストールすることもできます。FixKey が自動的にダウングレードすることはありません。

## トラブルシューティングとサポート

修正機能が無効になっている場合は、**診断とヘルプ**を開き、ステータスと理由コードを確認してください。権限を再確認し、別のアプリケーションにある編集可能なフィールドを試してください。編集可能なフィールドを待機中というステータスは、現在のフィールドを安全に識別できなかったことを意味します。修正機能が一時停止されていないか、またはアプリケーションが除外されていないかも確認してください。

ローカルの診断ログを確認するには**ログフォルダーを開く**を使用し、削除するには**ログを削除**を使用します。ログには入力内容ではなく、診断結果と理由コードが記録されます。FixKey が保持するログは最長7日分、合計で最大 10 MiB です。

サポートが必要な場合は、**診断とヘルプ**にある GitHub Issues のリンクを使用するか、[GitHub Issues](https://github.com/delinoio/apps/issues)を開いてください。FixKey のバージョン、オペレーティングシステム、影響を受けるアプリケーション、理由コードを記載してください。個人的なテキストや認証情報は含めないでください。
