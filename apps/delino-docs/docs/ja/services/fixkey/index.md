# FixKey

FixKeyは、誤ったキーボード配列で入力された単語を修正します。韓国語の2ボル式と米国英語のQWERTY配列の間で、システムの入力言語を切り替えることなく双方向に変換できます。FixKeyはデスクトップ上でローカルに動作し、アカウントは必要ありません。

## FixKeyをインストールする

[FixKeyのリリース](https://github.com/delinoio/apps/releases?q=fixkey%40)を開き、お使いのオペレーティングシステムとプロセッサに対応するパッケージを選択します。

- macOS ARM64：Appleシリコン用のDMG。FixKeyを「アプリケーション」に移動して開きます。
- Windows x64またはARM64：お使いのプロセッサ用のEXEインストーラー。Windows用パッケージにはAuthenticode発行元署名がないため、発行元不明またはSmartScreenの警告が表示される場合があります。
- Linux X11 x64またはARM64：お使いのプロセッサ用のAppImage。Waylandはサポートされていません。

最小実行要件は、Appleシリコン搭載のmacOS 11、WebView2を備えたWindows 10、またはX11、GTK 3、WebKitGTK 4.1、AT-SPIアクセシビリティバスを備えたLinuxです。これらは各プラットフォームの前提条件です。すべてのアプリケーションやテキストフィールドとの互換性を保証するものではありません。

## 権限を付与する

FixKeyが編集可能なフィールド内の現在の単語を読み取って置換するには、オペレーティングシステムのアクセシビリティ権限と入力権限が必要です。権限ダイアログの指示に従い、システム設定で要求されたアクセスを許可してから、**再確認**を選択します。必要な権限と同梱辞書の準備が整うまで、修正機能は無効のままです。パスワードフィールドと保護されたフィールドは対象外です。

macOSでは、「システム設定」の**アクセシビリティ**と**入力監視**を確認してください。アクセシビリティ権限によって、入力監視に個別の項目がなくても有効な入力アクセスが許可される場合があります。このリストを確認するには、FixKeyで**一般**を開き、**入力監視を設定**を選択します。FixKeyが表示されていない場合は、システムの権限リストで**+**を使用して、「アプリケーション」にある現在のFixKey.appを追加します。その後FixKeyに戻り、再確認してください。macOSですでに有効な入力アクセスが許可されている場合、リストに個別の項目は必要ありません。

## 単語を修正する

初期設定では、両方の配列が有効になっています。編集可能なフィールドに入力し、スペースまたは句読点で単語を終了します。FixKeyは、有効になっている各配列の候補を同梱辞書と照合します。有効な言語のうち正確に1つだけが候補を認識し、かつその候補が元の単語と異なる場合にのみ、単語を置換します。どの言語も候補を認識しない場合、または複数の言語が候補を認識する場合、単語は変更されません。

たとえば、キーシーケンス`rPthrgo`と`zlqhemrk`は、それぞれ`계속해`と`키보드가`になることがあります。これらの例は配列修正を示すものです。結果は、現在のフィールド、入力コンテキスト、辞書による認識に左右されます。

FixKeyは、修正した単語の後にある区切り文字を保持します。EnterとTabでは修正は実行されません。URLやメールアドレスで使用される句読点がある場合、FixKeyがトークン全体を分類できるようになるまで評価が遅れることがあります。文字の間にあるアポストロフィとハイフンは、単語内の一部として保持されます。

自動修正では、貼り付けられたテキスト、プログラムによって挿入されたテキスト、数字、絵文字、URL、メールアドレス、複数の文字体系が混在するトークンはスキップされます。また、韓国語入力の文字変換が完了するまで待機します。不明なフィールド、権限を利用できない場合、安全に変更できないフィールドは変更されません。

### 修正を元に戻す

自動修正の直後にBackspaceを押すと、元の単語とその区切り文字が復元されます。それ以降にBackspaceを押すと、通常どおり削除されます。キャレットの移動、選択範囲の変更、フィールドの切り替え、または別の単語の入力を開始すると、この即時取り消しのコンテキストは終了します。

### 候補を手動で選択する

1. **ショートカット**を開き、手動候補用のショートカットを割り当てます。初期設定では割り当てられていません。登録に失敗した場合は、表示された理由を確認するか、別のショートカットを選択してください。
2. 編集可能なフィールドに単語を入力し、ショートカットを使用します。
3. 矢印キーで候補を選択します。Enterを押すと適用され、Escを押すと候補選択画面が閉じます。

候補選択画面には、辞書による認識結果が表示されます。認識されていない候補を明示的に選択することもできます。元のキャレットを移動するか、アプリケーションを切り替えると、候補選択画面が閉じます。FixKeyが安全な置換対象を確立できない場合、候補選択画面は利用できません。

## 修正機能を設定する

**一般**では、修正機能の一時停止または再開、有効にする言語の選択、ログイン時の起動の有効化、インターフェースの言語とテーマの選択ができます。ログイン時の起動は初期設定ではオフです。設定は直ちに適用され、ローカルに保存されます。

特定のアプリケーションを変更せずに維持するには、**除外するアプリ**に追加します。除外対象は、単に表示名ではなくアプリケーション自体によって識別されます。解決できないアプリケーションも、確認できるようリストに残ります。

## プライバシーとオフラインでの使用

FixKeyは入力をデバイス上で処理します。入力テキスト、候補、文書の内容、ウィンドウタイトル、修正履歴を保存または送信することはありません。置換にクリップボードは使用しません。テレメトリ、リモートでのクラッシュレポート、自動的な診断情報のアップロードはありません。

辞書は同梱されているため、権限の準備が整えば、初回起動時からオフラインで修正機能を使用できます。辞書はアプリケーションの更新とともに変更されます。辞書を個別にダウンロードする機能や、ユーザー辞書の編集機能はありません。ネットワークの使用は、更新の確認とダウンロードに限定されます。

## FixKeyを更新する

FixKeyは、起動時、実行中は24時間ごと、または**更新**で確認を要求したときに、安定版の更新を確認します。ダウンロードとインストールにはユーザーの同意が必要です。更新ペイロードの署名が検証され、署名が無効な場合はインストールされません。インストール前に修正機能が停止し、設定は保持されます。

確認に失敗した場合は、手動で再試行するか、次回の定期確認まで待ってください。インストールに失敗した場合は、FixKeyを再起動するか、FixKeyのリリースから適切なパッケージを再インストールしてください。以前のリリースを手動で再インストールすることもできます。FixKeyが自動的にダウングレードすることはありません。

## トラブルシューティングとサポート

修正機能が無効な場合は、**診断とヘルプ**を開き、ステータスと理由コードを確認してください。権限を再確認し、別のアプリケーションにある編集可能なフィールドで試してください。「編集可能なフィールドを待機中」というステータスは、現在のフィールドを安全に識別できなかったことを意味します。また、修正機能が一時停止されていないか、アプリケーションが除外されていないかも確認してください。

**ログフォルダーを開く**を使用してローカルの診断ログを確認するか、**ログを削除**を使用して削除します。ログには入力内容ではなく、診断結果と理由コードが記録されます。FixKeyが保持するログは最長7日間、合計で最大10 MiBです。

ヘルプが必要な場合は、**診断とヘルプ**にあるGitHub Issuesのリンクを使用するか、[GitHub Issues](https://github.com/delinoio/apps/issues)を開いてください。FixKeyのバージョン、オペレーティングシステム、影響を受けるアプリケーション、理由コードを含めてください。個人的なテキストや認証情報は含めないでください。
