# Dienste

- [Delcore](/de/services/delcore/): Mandantenstatus über einen registrierten Dienst prüfen.
- [DevBase](/de/services/devbase/): Endbenutzer Ihrer Anwendungen verwalten.
- [Git Tracker](/de/services/git-tracker/): Commit-Messwerte und Regressionen verfolgen.
- [FixKey](/de/services/fixkey/): koreanische und englische Wörter korrigieren, die mit dem falschen Tastaturlayout eingegeben wurden.
- [DeliTools](/de/services/delitools/): Texte übersetzen und JSON aus Text mit kostenpflichtigen APIs extrahieren.

Eine Einführung in die Dokumentationswebsite finden Sie unter [Erste Schritte](/de/guide/getting-started).
