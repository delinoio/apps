# DeliTools-Konfiguration und Fehlerbehebung

Diese Seite hilft Ihnen, einen Client für DeliTools einzurichten und Fehler zu beheben. Regeln zu den Feldern finden Sie in der [API-Referenz](/de/services/delitools/api-reference).

## Ihren Client konfigurieren

- **Basis-URL.** Verwenden Sie die URL des DeliTools-API-Servers, die Ihnen Ihr Dienstbetreiber mitteilt. Die Prozeduren sind unter `/delitools.v1.DelitoolsService/Translate` und `/delitools.v1.DelitoolsService/Extract` verfügbar.
- **Protokoll.** Verwenden Sie einen Connect-Client oder senden Sie JSON mit `POST` und `Content-Type: application/json`. JSON-Feldnamen verwenden lowerCamelCase.
- **Zugangsdaten.** Senden Sie `Authorization: Bearer <credential>`. Verwenden Sie ein Delino-Anmeldetoken oder einen API-Schlüssel, der mit `dlk_` beginnt. Bewahren Sie Schlüssel im serverseitigen Code auf. DeliTools unterstützt keine Aufrufe aus Browsern.
- **Mandant.** Ein Anmeldetoken benötigt `tenantId`. Ein API-Schlüssel identifiziert seinen Mandanten bereits; wenn Sie zusätzlich `tenantId` senden, muss der Wert übereinstimmen.
- **Modell.** Verwenden Sie eine Modellkennung, die der Betreiber zulässt. Die Extraktion verwendet ein festes Modell und hat kein `model`-Feld.
- **Zeitlimits.** Legen Sie ein Client-Zeitlimit fest, das zu Ihrer größten Anfrage passt. Ein Anbieteraufruf kann mehrere Sekunden dauern, und DeliTools kann bei vorübergehenden Fehlern Wiederholungsversuche durchführen, sodass der gesamte Aufruf länger dauern kann. Eine Anfrage, die das Ausführungszeitlimit des Betreibers überschreitet, gibt `ERROR_REASON_TIMEOUT` zurück; wenn Ihr eigenes Zeitlimit den Aufruf zuerst beendet, behandelt DeliTools dies als Abbruch.
- **Wiederholungsversuche.** Wiederholen Sie Anfragen bei `ERROR_REASON_RATE_LIMITED`, `ERROR_REASON_PROVIDER_FAILED`, `ERROR_REASON_DEPENDENCY_UNAVAILABLE` und `ERROR_REASON_TIMEOUT` mit exponentiell zunehmender Wartezeit und einer kleinen zufälligen Verzögerung. Jeder Wiederholungsversuch ist eine neue Ausführung, die berechnet werden kann. Siehe [Abrechnung](/de/services/delitools/billing). Wiederholen Sie keine unveränderten Anfragen, deren Validierung fehlschlägt.

## Einen Fehler beheben

| Grund                                 | Vorgehensweise                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ERROR_REASON_INVALID_INPUT`          | Korrigieren Sie die Anfrage. Prüfen Sie auf leere Zeichenfolgen und überprüfen Sie die Sprach-Tags, die Mandanten-ID, das Modell und ob das Schema gültiges JSON ist.                                                                                                                                                                                                                                                           |
| `ERROR_REASON_UNAUTHENTICATED`        | Überprüfen Sie das Token oder den Schlüssel. Möglicherweise wurde es bzw. er falsch eingegeben, ist abgelaufen, wurde widerrufen oder gehört zu einem gelöschten Mandanten. Erstellen Sie einen neuen Schlüssel, wenn Sie das Geheimnis verloren haben. Wenn plötzlich jeder gültige Schlüssel fehlschlägt, informieren Sie den Dienstbetreiber: Eine falsch konfigurierte Dienstidentität lässt Schlüssel ungültig erscheinen. |
| `ERROR_REASON_PERMISSION_DENIED`      | Prüfen Sie, ob der Schlüssel `translate` oder `extract` erlaubt, ob der Benutzer weiterhin über die Berechtigung im Mandanten verfügt und ob jede von Ihnen gesendete `tenantId` dem Mandanten des Schlüssels entspricht.                                                                                                                                                                                                       |
| `ERROR_REASON_BILLING_BLOCKED`        | Beheben Sie das Abrechnungsproblem in Delcore, etwa bezüglich des Guthabens oder der Verlängerung, und versuchen Sie es dann erneut.                                                                                                                                                                                                                                                                                            |
| `ERROR_REASON_LIMIT_EXCEEDED`         | Senden Sie weniger Daten: weniger Elemente, kürzeren Text oder ein kleineres Schema. Teilen Sie große Aufgaben in mehrere Anfragen auf.                                                                                                                                                                                                                                                                                         |
| `ERROR_REASON_RATE_LIMITED`           | Verringern Sie die Anfragerate und die Anzahl gleichzeitiger Anfragen und versuchen Sie es nach einer kurzen Verzögerung erneut.                                                                                                                                                                                                                                                                                                |
| `ERROR_REASON_MODEL_UNAVAILABLE`      | Wenn der Fehler `invalid_argument` lautet, ist das Modell nicht zugelassen: Wählen Sie ein anderes. Lautet er `failed_precondition`, bitten Sie den Betreiber, die Preise des Modells zu registrieren.                                                                                                                                                                                                                          |
| `ERROR_REASON_UNSUPPORTED_SCHEMA`     | Entfernen Sie Schlüsselwörter außerhalb der [unterstützten Teilmenge](/de/services/delitools/api-reference). Die Wurzel muss ein Objektschema sein.                                                                                                                                                                                                                                                                             |
| `ERROR_REASON_PROVIDER_FAILED`        | Warten Sie und versuchen Sie es erneut. Wenn das Problem weiterhin besteht, wenden Sie sich mit der Anfrage-ID an den Betreiber.                                                                                                                                                                                                                                                                                                |
| `ERROR_REASON_INVALID_OUTPUT`         | Versuchen Sie es einmal erneut. Vereinfachen Sie das Schema oder die Eingabe, wenn der Fehler erneut auftritt. Der Versuch wird berechnet.                                                                                                                                                                                                                                                                                      |
| `ERROR_REASON_EXTRACTION_FAILED`      | Im Text fehlen erforderliche Informationen. Ergänzen Sie die fehlenden Angaben oder machen Sie die Eigenschaft in Ihrem Schema optional. Der Versuch wird berechnet.                                                                                                                                                                                                                                                            |
| `ERROR_REASON_TIMEOUT`                | Senden Sie kleinere Anfragen. Versuchen Sie es später erneut.                                                                                                                                                                                                                                                                                                                                                                   |
| `ERROR_REASON_CANCELED`               | Ihr Client hat die Verbindung geschlossen. Prüfen Sie, ob Client-Zeitlimits überschritten wurden oder der Client beendet wurde.                                                                                                                                                                                                                                                                                                 |
| `ERROR_REASON_DEPENDENCY_UNAVAILABLE` | Versuchen Sie es später erneut. DeliTools lehnt kostenpflichtige Aufgaben ab, wenn es die Autorisierung nicht prüfen kann.                                                                                                                                                                                                                                                                                                      |

## Häufige Probleme

- **Ein Schlüssel funktioniert bei einer Anfrage und schlägt bei der nächsten fehl.** Ein Schlüssel, der abgelaufen ist, widerrufen wurde oder einem Benutzer gehört, der seine Berechtigung verloren hat, funktioniert sofort nicht mehr. Überprüfen Sie ihn mit `ListApiKeys`.
- **Ein einfacher `resource_exhausted`-Fehler ohne Grund.** Ihr Anfrageinhalt ist größer als die allgemeine Größenbeschränkung des Betreibers. Senden Sie weniger Daten.
- **Ein Ergebnis sieht falsch aus.** Modelle können Fehler machen, und ein Ergebnis, das Ihrem Schema entspricht, ist nicht unbedingt korrekt. Formulieren Sie die Anweisungen in den `description`-Feldern Ihres Schemas klarer und überprüfen Sie wichtige Werte.
- **Unerwartete Kosten.** Fehlgeschlagene Versuche mit bekanntem Verbrauch und wiederholte Anfragen werden berechnet. Siehe [Abrechnung](/de/services/delitools/billing).
- **Noch kein Verbrauch sichtbar.** Der Verbrauch wird kurz nach dem Aufruf an Delcore übermittelt. Prüfen Sie dies später erneut.

## Support anfordern

Geben Sie die Anfrage-ID aus dem Antwortinhalt oder dem Header `X-Delitools-Request-Id`, den Prozedurnamen, den Zeitpunkt und den Fehlergrund an. Senden Sie weder Ihren API-Schlüssel noch Ihr Anmeldetoken oder die von Ihnen übermittelten Texte.
