# DeliTools-Konfiguration und Fehlerbehebung

Diese Seite hilft Ihnen, einen Client für DeliTools einzurichten und Fehler zu beheben. Regeln für Felder finden Sie in der [API-Referenz](/de/services/delitools/api-reference).

## Ihren Client konfigurieren

- **Basis-URL.** Verwenden Sie die URL des DeliTools-API-Servers, die Ihnen Ihr Dienstbetreiber bereitstellt. Die Prozeduren sind unter `/delitools.v1.DelitoolsService/Translate` und `/delitools.v1.DelitoolsService/Extract` verfügbar.
- **Protokoll.** Verwenden Sie einen Connect-Client oder senden Sie JSON mit `POST` und `Content-Type: application/json`. JSON-Feldnamen verwenden lowerCamelCase.
- **Zugangsdaten.** Senden Sie `Authorization: Bearer <credential>`. Verwenden Sie ein Delino-Anmeldetoken oder einen API-Schlüssel, der mit `dlk_` beginnt. Bewahren Sie Schlüssel im serverseitigen Code auf. DeliTools unterstützt keine Aufrufe aus Browsern.
- **Mandant.** Ein Anmeldetoken benötigt `tenantId`. Ein API-Schlüssel identifiziert seinen Mandanten bereits; wenn Sie zusätzlich `tenantId` senden, muss der Wert übereinstimmen.
- **Modell.** Verwenden Sie eine Modellkennung, die der Betreiber zulässt. Die Extraktion verwendet ein festes Modell und hat kein `model`-Feld.
- **Zeitüberschreitungen.** Legen Sie ein Client-Zeitlimit fest, das für Ihre größte Anfrage geeignet ist. Ein Anbieteraufruf kann mehrere Sekunden dauern, und DeliTools kann bei vorübergehenden Fehlern Wiederholungsversuche durchführen, sodass der gesamte Aufruf länger dauern kann. Eine Anfrage, die das Ausführungszeitlimit des Betreibers überschreitet, gibt `ERROR_REASON_TIMEOUT` zurück; wenn Ihr eigenes Zeitlimit den Aufruf vorher beendet, behandelt DeliTools dies als Abbruch.
- **Wiederholungsversuche.** Wiederholen Sie Anfragen bei `ERROR_REASON_RATE_LIMITED`, `ERROR_REASON_DEPENDENCY_UNAVAILABLE` und `ERROR_REASON_TIMEOUT` sowie bei `ERROR_REASON_PROVIDER_FAILED` nur dann, wenn der Connect-Code `unavailable` lautet. Verwenden Sie dabei exponentielles Backoff und eine kleine zufällige Verzögerung. Jeder Wiederholungsversuch ist eine neue Ausführung, die berechnet werden kann. Siehe [Abrechnung](/de/services/delitools/billing). Wiederholen Sie Anfragen, deren Validierung fehlschlägt, nicht unverändert.

## Einen Fehler beheben

| Grund                                 | Vorgehensweise                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ERROR_REASON_INVALID_INPUT`          | Korrigieren Sie die Anfrage. Prüfen Sie auf leere Zeichenfolgen, Sprach-Tags, die Mandanten-ID, das Modell und darauf, ob das Schema gültiges JSON ist.                                                                                                                                                                                                                                                                       |
| `ERROR_REASON_UNAUTHENTICATED`        | Prüfen Sie das Token oder den Schlüssel. Es bzw. er ist möglicherweise falsch eingegeben, abgelaufen, widerrufen oder gehört zu einem gelöschten Mandanten. Erstellen Sie einen neuen Schlüssel, wenn Sie den geheimen Schlüsselwert verloren haben. Wenn plötzlich alle gültigen Schlüssel fehlschlagen, informieren Sie den Dienstbetreiber: Eine falsch konfigurierte Dienstidentität lässt Schlüssel ungültig erscheinen. |
| `ERROR_REASON_PERMISSION_DENIED`      | Prüfen Sie, ob der Schlüssel `translate` oder `extract` erlaubt, ob der Benutzer weiterhin im Mandanten berechtigt ist und ob jede von Ihnen gesendete `tenantId` dem Mandanten des Schlüssels entspricht.                                                                                                                                                                                                                    |
| `ERROR_REASON_BILLING_BLOCKED`        | Beheben Sie das Abrechnungsproblem in Delcore, etwa beim Guthaben oder der Verlängerung, und versuchen Sie es dann erneut.                                                                                                                                                                                                                                                                                                    |
| `ERROR_REASON_LIMIT_EXCEEDED`         | Senden Sie weniger Daten: weniger Elemente, kürzeren Text oder ein kleineres Schema. Teilen Sie große Aufträge in mehrere Anfragen auf.                                                                                                                                                                                                                                                                                       |
| `ERROR_REASON_RATE_LIMITED`           | Verlangsamen Sie die Aufrufe, reduzieren Sie gleichzeitige Anfragen und versuchen Sie es nach einer kurzen Verzögerung erneut.                                                                                                                                                                                                                                                                                                |
| `ERROR_REASON_MODEL_UNAVAILABLE`      | Wenn der Fehler `invalid_argument` lautet, ist das Modell nicht zulässig: Wählen Sie ein anderes. Bei `failed_precondition` bitten Sie den Betreiber, die Preise des Modells zu registrieren.                                                                                                                                                                                                                                 |
| `ERROR_REASON_UNSUPPORTED_SCHEMA`     | Entfernen Sie Schlüsselwörter außerhalb der [unterstützten Teilmenge](/de/services/delitools/api-reference). Die Wurzel muss ein Objektschema sein.                                                                                                                                                                                                                                                                           |
| `ERROR_REASON_PROVIDER_FAILED`        | Warten Sie beim Connect-Code `unavailable` und versuchen Sie es erneut. Bei `internal` hat der Anbieter die Anfrage abgelehnt: Wiederholen Sie sie nicht unverändert, prüfen Sie die Anfrage und kontaktieren Sie den Betreiber unter Angabe der Anfrage-ID.                                                                                                                                                                  |
| `ERROR_REASON_INVALID_OUTPUT`         | Versuchen Sie es einmal erneut. Vereinfachen Sie das Schema oder die Eingabe, wenn der Fehler erneut auftritt. Der Versuch wird berechnet.                                                                                                                                                                                                                                                                                    |
| `ERROR_REASON_EXTRACTION_FAILED`      | Im Text fehlen erforderliche Informationen. Geben Sie die fehlenden Details an oder machen Sie die Eigenschaft in Ihrem Schema optional. Der Versuch wird berechnet.                                                                                                                                                                                                                                                          |
| `ERROR_REASON_TIMEOUT`                | Senden Sie kleinere Anfragen. Versuchen Sie es später erneut.                                                                                                                                                                                                                                                                                                                                                                 |
| `ERROR_REASON_CANCELED`               | Ihr Client hat die Verbindung geschlossen. Prüfen Sie auf clientseitige Zeitüberschreitungen oder Abschaltungen.                                                                                                                                                                                                                                                                                                              |
| `ERROR_REASON_DEPENDENCY_UNAVAILABLE` | Versuchen Sie es später erneut. DeliTools lehnt kostenpflichtige Aufträge ab, wenn es die Autorisierung nicht prüfen kann.                                                                                                                                                                                                                                                                                                    |

## Häufige Probleme

- **Ein Schlüssel funktioniert bei einer Anfrage und schlägt bei der nächsten fehl.** Ein Schlüssel, der abgelaufen ist, widerrufen wurde oder einem Benutzer gehört, der seine Berechtigung verloren hat, funktioniert sofort nicht mehr. Prüfen Sie ihn mit `ListApiKeys`.
- **Ein einfacher `resource_exhausted`-Fehler ohne Grund.** Ihr Anfragetext ist größer als die vom Betreiber festgelegte Gesamtgrößenbeschränkung. Senden Sie weniger Daten.
- **Ein Ergebnis sieht falsch aus.** Modelle können Fehler machen, und ein Ergebnis, das Ihrem Schema entspricht, ist nicht unbedingt korrekt. Formulieren Sie die Anweisungen in den `description`-Feldern Ihres Schemas klarer und überprüfen Sie wichtige Werte.
- **Unerwartete Kosten.** Fehlgeschlagene Versuche mit bekannter Nutzung und wiederholte Anfragen werden berechnet. Siehe [Abrechnung](/de/services/delitools/billing).
- **Noch keine Nutzung sichtbar.** Die Nutzungsdaten erreichen Delcore kurz nach dem Aufruf. Prüfen Sie später erneut.

## Support anfordern

Geben Sie die Anfrage-ID aus dem Antworttext oder dem Header `X-Delitools-Request-Id`, den Prozedurnamen, den Zeitpunkt und den Fehlergrund an. Senden Sie weder Ihren API-Schlüssel noch Ihr Anmeldetoken oder die von Ihnen übermittelten Texte.
