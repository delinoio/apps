# Serviços

- [Delcore](/pt-BR/services/delcore/): verifique o estado do tenant a partir de um serviço registrado.
- [DevBase](/pt-BR/services/devbase/): gerencie os usuários finais das suas aplicações.
- [Git Tracker](/pt-BR/services/git-tracker/): acompanhe métricas de commits e regressões.
- [FixKey](/pt-BR/services/fixkey/): corrija palavras em coreano e inglês digitadas com o layout de teclado incorreto.

Consulte [Primeiros passos](/pt-BR/guide/getting-started) para uma introdução ao site da documentação.
