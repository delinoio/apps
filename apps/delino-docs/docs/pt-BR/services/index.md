# Serviços

- [Delcore](/pt-BR/services/delcore/): verifique o estado do tenant a partir de um serviço registrado.
- [DevBase](/pt-BR/services/devbase/): gerencie os usuários finais dos seus aplicativos.
- [Git Tracker](/pt-BR/services/git-tracker/): acompanhe medições de commits e regressões.
- [DeliTools](/pt-BR/services/delitools/): traduza textos e extraia JSON de textos com APIs pagas.

Consulte [Primeiros passos](/pt-BR/guide/getting-started) para uma introdução ao site de documentação.
