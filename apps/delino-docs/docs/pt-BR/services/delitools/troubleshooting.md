# Configuração e solução de problemas do DeliTools

Esta página ajuda você a configurar um cliente para o DeliTools e corrigir erros. Para conhecer as regras dos campos, consulte a [referência da API](/pt-BR/services/delitools/api-reference).

## Configure seu cliente

- **URL base.** Use a URL do servidor da API do DeliTools fornecida pelo operador do serviço. Os procedimentos estão em `/delitools.v1.DelitoolsService/Translate` e `/delitools.v1.DelitoolsService/Extract`.
- **Protocolo.** Use um cliente Connect ou envie JSON com `POST` e `Content-Type: application/json`. Os nomes dos campos JSON usam lowerCamelCase.
- **Credencial.** Envie `Authorization: Bearer <credential>`. Use um token de login do Delino ou uma chave de API que comece com `dlk_`. Mantenha as chaves no código do lado do servidor. O DeliTools não oferece suporte a chamadas de navegadores.
- **Tenant.** Um token de login exige `tenantId`. Uma chave de API já identifica seu tenant; se você também enviar `tenantId`, ele deverá corresponder.
- **Modelo.** Use um identificador de modelo permitido pelo operador. A extração usa um modelo fixo e não tem o campo `model`.
- **Tempos limite.** Defina um tempo limite no cliente adequado à sua maior solicitação. Uma chamada ao provedor pode levar vários segundos, e o DeliTools pode tentar novamente em caso de falhas transitórias, portanto a chamada completa pode demorar mais. Uma solicitação que excede o tempo limite de execução do operador retorna `ERROR_REASON_TIMEOUT`; se o seu próprio tempo limite encerrar a chamada primeiro, o DeliTools a tratará como um cancelamento.
- **Novas tentativas.** Tente novamente em caso de `ERROR_REASON_RATE_LIMITED`, `ERROR_REASON_PROVIDER_FAILED`, `ERROR_REASON_DEPENDENCY_UNAVAILABLE` e `ERROR_REASON_TIMEOUT`, com espera exponencial e um pequeno atraso aleatório. Cada nova tentativa é uma nova execução que pode ser cobrada. Consulte [Cobrança](/pt-BR/services/delitools/billing). Não repita solicitações sem alterações que falhem na validação.

## Corrija um erro

| Motivo                                | O que fazer                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ERROR_REASON_INVALID_INPUT`          | Corrija a solicitação. Verifique se há strings vazias, as tags de idioma, o ID do tenant, o modelo e se o esquema é um JSON válido.                                                                                                                                                                                                                     |
| `ERROR_REASON_UNAUTHENTICATED`        | Verifique o token ou a chave. Ele pode ter sido digitado incorretamente, expirado, revogado ou pertencer a um tenant excluído. Crie uma nova chave se você perdeu o segredo. Se todas as chaves válidas falharem de repente, avise o operador do serviço: uma identidade de serviço configurada incorretamente faz com que as chaves pareçam inválidas. |
| `ERROR_REASON_PERMISSION_DENIED`      | Verifique se a chave concede `translate` ou `extract`, se o usuário ainda tem permissão no tenant e se qualquer `tenantId` enviado é o tenant da chave.                                                                                                                                                                                                 |
| `ERROR_REASON_BILLING_BLOCKED`        | Resolva o problema de cobrança no Delcore, como o saldo ou a renovação, e tente novamente.                                                                                                                                                                                                                                                              |
| `ERROR_REASON_LIMIT_EXCEEDED`         | Envie menos dados: menos itens, texto mais curto ou um esquema menor. Divida tarefas grandes em várias solicitações.                                                                                                                                                                                                                                    |
| `ERROR_REASON_RATE_LIMITED`           | Diminua o ritmo, reduza as solicitações simultâneas e tente novamente após um breve intervalo.                                                                                                                                                                                                                                                          |
| `ERROR_REASON_MODEL_UNAVAILABLE`      | Se o erro for `invalid_argument`, o modelo não é permitido: escolha outro. Se for `failed_precondition`, peça ao operador para cadastrar os preços do modelo.                                                                                                                                                                                           |
| `ERROR_REASON_UNSUPPORTED_SCHEMA`     | Remova as palavras-chave que não fazem parte do [subconjunto compatível](/pt-BR/services/delitools/api-reference). A raiz deve ser um esquema de objeto.                                                                                                                                                                                                |
| `ERROR_REASON_PROVIDER_FAILED`        | Aguarde e tente novamente. Se o problema persistir, entre em contato com o operador e informe o ID da solicitação.                                                                                                                                                                                                                                      |
| `ERROR_REASON_INVALID_OUTPUT`         | Tente novamente uma vez. Simplifique o esquema ou a entrada se o erro se repetir. A tentativa é cobrada.                                                                                                                                                                                                                                                |
| `ERROR_REASON_EXTRACTION_FAILED`      | O texto não contém as informações obrigatórias. Forneça os detalhes ausentes ou torne a propriedade opcional no seu esquema. A tentativa é cobrada.                                                                                                                                                                                                     |
| `ERROR_REASON_TIMEOUT`                | Envie solicitações menores. Tente novamente mais tarde.                                                                                                                                                                                                                                                                                                 |
| `ERROR_REASON_CANCELED`               | Seu cliente encerrou a conexão. Verifique se houve tempos limite ou encerramentos do cliente.                                                                                                                                                                                                                                                           |
| `ERROR_REASON_DEPENDENCY_UNAVAILABLE` | Tente novamente mais tarde. O DeliTools recusa tarefas pagas quando não consegue verificar a autorização.                                                                                                                                                                                                                                               |

## Problemas comuns

- **Uma chave funciona em uma solicitação e falha na seguinte.** Uma chave que expirou, foi revogada ou pertence a um usuário que perdeu a permissão para de funcionar imediatamente. Verifique-a com `ListApiKeys`.
- **Um erro `resource_exhausted` sem um motivo.** O corpo da sua solicitação é maior que o limite geral de tamanho definido pelo operador. Envie menos dados.
- **Um resultado parece incorreto.** Os modelos podem cometer erros, e um resultado que segue seu esquema não é necessariamente correto. Torne mais claras as instruções nos campos `description` do seu esquema e confira os valores importantes.
- **Cobranças inesperadas.** Tentativas com falha cujo uso é conhecido e solicitações repetidas são cobradas. Consulte [Cobrança](/pt-BR/services/delitools/billing).
- **O uso ainda não aparece.** O uso chega ao Delcore pouco depois da chamada. Verifique novamente mais tarde.

## Solicite suporte

Inclua o ID da solicitação presente no corpo da resposta ou no cabeçalho `X-Delitools-Request-Id`, o nome do procedimento, o horário e o motivo do erro. Não envie sua chave de API, seu token de login nem os textos que você enviou.
