# 服务

- [Delcore](/zh-Hans/services/delcore/)：从已注册的服务中检查租户状态。
- [DevBase](/zh-Hans/services/devbase/)：管理应用程序的最终用户。
- [Git Tracker](/zh-Hans/services/git-tracker/)：跟踪提交的度量数据和回归问题。
- [DeliTools](/zh-Hans/services/delitools/)：使用付费 API 翻译文本并从文本中提取 JSON。

有关文档站点的介绍，请参阅[入门指南](/zh-Hans/guide/getting-started)。
