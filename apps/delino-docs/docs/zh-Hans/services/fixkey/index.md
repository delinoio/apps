# FixKey

FixKey 可纠正因使用错误键盘布局而输入的单词。它支持韩语两套式键盘和美式英语 QWERTY 键盘布局之间的双向转换，无需切换系统输入语言。FixKey 在桌面设备上本地运行，无需账户。

## 安装 FixKey

打开 [FixKey 发布页面](https://github.com/delinoio/apps/releases?q=fixkey%40)，根据您的操作系统和处理器选择安装包：

- macOS ARM64：适用于 Apple 芯片的 DMG。将 FixKey 移到“应用程序”文件夹，然后打开它。
- Windows x64 或 ARM64：选择适用于您处理器的 EXE 安装程序。Windows 安装包没有 Authenticode 发布者签名，因此 Windows 可能会显示未知发布者或 SmartScreen 警告。
- Linux X11 x64 或 ARM64：选择适用于您处理器的 AppImage。不支持 Wayland。

最低运行要求为：搭载 Apple 芯片的 macOS 11；安装了 WebView2 的 Windows 10；或配备 X11、GTK 3、WebKitGTK 4.1 和 AT-SPI 辅助功能总线的 Linux。这些是平台前置条件，并不代表 FixKey 与所有应用程序或文本字段均兼容。

## 授予权限

FixKey 需要操作系统的辅助功能和输入权限，才能读取并替换可编辑字段中的当前单词。请按照权限对话框的指引，在系统设置中授予所请求的访问权限，然后选择**重新检查**。在所需权限和内置词典准备就绪之前，纠正功能将保持未启用状态。密码字段和受保护字段不在处理范围内。

在 macOS 上，请检查“系统设置”中的**辅助功能**和**输入监控**。辅助功能权限可能会授予有效的输入访问权限，而无需在“输入监控”中单独列出。要检查该列表，请在 FixKey 中打开**常规**，然后选择**设置输入监控**。如果列表中没有 FixKey，请在系统权限列表中使用 **+** 添加“应用程序”文件夹内当前的 FixKey.app，然后返回 FixKey 并重新检查。如果 macOS 已授予有效的输入访问权限，则不要求在该列表中单独显示 FixKey。

## 纠正单词

默认情况下，两种布局均已启用。在可编辑字段中输入内容，并以空格或标点符号结束一个单词。FixKey 会使用内置词典检查已启用布局对应的候选词。仅当恰好有一种已启用的语言能够识别其候选词，且该候选词与原始单词不同时，FixKey 才会替换该单词。如果没有任何语言或有多种语言识别出候选词，该单词将保持不变。

例如，按键序列 `rPthrgo` 和 `zlqhemrk` 可以转换为 `계속해` 和 `키보드가`。这些示例用于说明布局纠正；实际结果取决于当前字段、输入上下文和词典识别结果。

FixKey 会保留纠正后单词之后的分隔符。Enter 和 Tab 不会触发纠正。URL 或电子邮件地址中使用的标点符号可能会推迟判断，直到 FixKey 能够对完整词元进行分类。字母之间的撇号和连字符会保留在单词内部。

自动纠正会跳过粘贴或通过程序插入的文本、数字、表情符号、URL、电子邮件地址以及混合文字体系的词元。它会等待韩语输入组合完成。未知字段、权限不可用的情况以及无法安全修改的字段均不会被更改。

### 撤销纠正

在自动纠正后立即按 Backspace，可恢复原始单词及其分隔符。继续按 Backspace 将正常删除内容。移动插入光标、更改选择范围、切换字段或开始输入另一个单词，都会结束这一即时撤销上下文。

### 手动选择候选词

1. 打开**快捷键**，为手动候选词功能指定快捷键。默认情况下未指定快捷键。如果注册失败，请查看显示的原因或选择其他快捷键。
2. 在可编辑字段中输入一个单词，然后使用该快捷键。
3. 使用方向键选择候选词。按 Enter 应用，或按 Esc 关闭选择器。

选择器会显示词典识别结果。您也可以明确选择未被识别的候选词。移动源字段中的插入光标或切换应用程序会关闭选择器。当 FixKey 无法确定安全的替换目标时，选择器不可用。

## 配置纠正功能

在**常规**中，您可以暂停或恢复纠正功能、选择启用的语言、启用登录时启动，以及选择界面语言和主题。登录时启动默认关闭。设置会立即生效并保存在本地。

如果要让某个应用程序中的内容保持不变，请将其添加到**排除的应用**中。排除项根据应用程序本身而非仅根据其显示名称来识别。无法解析的应用程序仍会保留在列表中，以便您查看。

## 隐私与离线使用

FixKey 在您的设备上处理输入。它绝不会保存或传输输入文本、候选词、文档内容、窗口标题或纠正历史记录。它不会使用剪贴板进行替换。FixKey 不包含遥测、远程崩溃报告或自动诊断上传功能。

词典已内置，因此首次启动后，只要权限准备就绪，纠正功能即可离线工作。词典会随应用程序更新而变化；没有单独的词典下载，也不提供用户词典编辑器。网络仅用于检查和下载更新。

## 更新 FixKey

FixKey 会在启动时、运行期间每 24 小时以及您在**更新**中请求检查时，检查稳定版更新。下载和安装均需征得您的同意。系统会验证更新载荷的签名；签名无效将阻止安装。安装前纠正功能会停止，设置则会保留。

检查失败后，请手动重试或等待下一次计划检查。如果安装失败，请重新启动 FixKey，或从 FixKey 发布页面重新安装适当的安装包。您可以手动重新安装以前的版本；FixKey 绝不会自动降级。

## 故障排除与支持

如果纠正功能未启用，请打开**诊断与帮助**并查看状态和原因代码。重新检查权限，并尝试在其他应用程序的可编辑字段中使用。显示“正在等待可编辑字段”的状态，表示无法安全识别当前字段。另请检查纠正功能是否已暂停，或该应用程序是否已被排除。

使用**打开日志文件夹**可查看本地诊断日志，使用**删除日志**可将其移除。日志包含诊断结果和原因代码，而不包含输入内容。FixKey 最多保留七天的日志，日志总大小最多为 10 MiB。

如需帮助，请使用**诊断与帮助**中的 GitHub Issues 链接，或打开 [GitHub Issues](https://github.com/delinoio/apps/issues)。请提供 FixKey 版本、操作系统、受影响的应用程序和原因代码。请勿提供私密文本或凭据。
