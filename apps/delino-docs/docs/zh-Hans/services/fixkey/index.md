# FixKey

FixKey 可以纠正因使用错误键盘布局而输入的单词。它支持韩语两式键盘（Dubeolsik）和美式英语 QWERTY 键盘，并可在两者之间双向转换。FixKey 在您的桌面设备上本地运行，无需账户。

## 安装 FixKey

打开 [FixKey 发布页面](https://github.com/delinoio/apps/releases?q=fixkey%40)，并根据您的操作系统和处理器选择安装包：

- macOS ARM64：适用于 Apple 芯片的 DMG。将 FixKey 移至“应用程序”，然后打开它。
- Windows x64 或 ARM64：适用于相应处理器的 EXE 安装程序。Windows 安装包没有 Authenticode 发布者签名，因此 Windows 可能会显示未知发布者或 SmartScreen 警告。
- Linux X11 x64 或 ARM64：适用于相应处理器的 AppImage。不支持 Wayland。

最低运行环境要求为：搭载 Apple 芯片的 macOS 11；安装了 WebView2 的 Windows 10；或配备 X11、GTK 3、WebKitGTK 4.1 和 AT-SPI 辅助功能总线的 Linux。这些是平台先决条件，并不代表与所有应用程序或文本字段均兼容。

## 授予权限

FixKey 需要操作系统的辅助功能和输入权限，才能读取并替换可编辑字段中的当前单词。请按照权限对话框的提示，在系统设置中授予所需访问权限，然后选择**重新检查**。在所需权限和内置词典准备就绪之前，纠正功能将保持未启用状态。密码字段和受保护字段不在处理范围内。

在 macOS 上，请在“系统设置”中检查**辅助功能**和**输入监控**。辅助功能权限可能会授予有效的输入访问权限，而无需单独出现在“输入监控”列表中。要检查该列表，请在 FixKey 中打开**通用**，然后选择**设置输入监控**。如果列表中没有 FixKey，请使用系统权限列表中的 **+** 添加“应用程序”文件夹中当前的 FixKey.app，然后返回 FixKey 并重新检查。如果 macOS 已授予有效的输入访问权限，则无需单独的列表条目。

## 纠正单词

默认情况下，两种布局均处于启用状态。在可编辑字段中输入内容，并使用空格或标点结束一个单词。FixKey 会依据其内置词典，检查已启用布局所对应的候选项。仅当恰好有一种已启用语言能够识别其候选项，并且该候选项与原始内容不同时，FixKey 才会替换该单词。如果没有任何语言或有多种语言能够识别某个候选项，则单词保持不变。

例如，按键序列 `rPthrgo` 和 `zlqhemrk` 可以变为 `계속해` 和 `키보드가`。这些示例用于说明布局纠正；实际结果取决于当前字段、输入上下文和词典识别情况。

FixKey 会保留已纠正单词后的分隔符。Enter 和 Tab 不会触发纠正。URL 或电子邮件地址中使用的标点可能会推迟检测，直到 FixKey 能够对整个词元进行分类。字母之间的撇号和连字符会保留在单词内部。

自动纠正会跳过粘贴或以编程方式插入的文本、数字、表情符号、URL、电子邮件地址以及混合文字系统的词元。它会等待韩语输入组合完成。无法识别的字段、权限不可用的情况，以及无法安全修改的字段都不会被更改。

在 macOS 或 Windows 上成功完成自动纠正后，FixKey 还会尝试为纠正后的语言选择已启用的输入源。在 Windows 上，它可以使用 Microsoft 韩语 IME 的韩文和拉丁字母模式，即使未启用单独的美式 QWERTY 输入源也可以。请将您的韩语 IME 配置为两式键盘。如果无法选择输入源或选择失败，纠正后的文本和即时撤销功能仍然可用。FixKey 不会更改已关闭或不受支持的 Windows IME。Linux 会保留当前输入源。即时撤销不会再次更改输入源。

### 撤销纠正

在自动纠正后立即按 Backspace，可恢复原始单词及其分隔符。之后继续按 Backspace 将正常删除内容。移动插入符、改变选区、切换字段或开始输入另一个单词，都会结束此次即时撤销上下文。

### 手动选择候选项

1. 打开**快捷键**，为手动选择候选项分配快捷键。默认情况下未分配快捷键。如果注册失败，请查看显示的原因或选择其他快捷键。
2. 在可编辑字段中输入一个单词，然后使用该快捷键。
3. 使用方向键选择候选项。按 Enter 应用候选项，或按 Esc 关闭选择器。

选择器会显示词典识别结果。您也可以明确选择未被识别的候选项。移动源字段中的插入符或切换应用程序会关闭选择器。当 FixKey 无法确定安全的替换目标时，选择器不可用。

## 配置纠正功能

在**通用**中，您可以暂停或恢复纠正、选择启用的语言、启用登录时启动，以及选择界面语言和主题。默认情况下，登录时启动处于关闭状态。设置会立即生效并保存在本地。

要让某个应用程序中的内容保持不变，请将其添加到**排除的应用**中。排除项根据应用程序本身进行识别，而非仅依据其显示名称。无法解析的应用程序仍会保留在列表中，供您检查。

## 隐私和离线使用

FixKey 在您的设备上处理输入内容。它绝不会保存或传输输入文本、候选项、文档内容、窗口标题或纠正历史记录。它不会使用剪贴板进行替换。FixKey 不含遥测、远程崩溃报告或自动诊断信息上传功能。

词典已内置，因此在首次启动并准备好权限后，纠正功能即可离线工作。词典会随应用程序更新而变化；没有单独的词典下载功能或用户词典编辑器。网络仅用于检查和下载更新。

## 更新 FixKey

FixKey 会在启动时、运行期间每 24 小时，以及您在**更新**中主动请求检查时，检查稳定版更新。下载和安装需要征得您的同意。系统会验证更新载荷的签名，签名无效时将阻止安装。安装前纠正功能会停止，设置则会保留。

检查失败后，请手动重试或等待下一次计划检查。如果安装失败，请重新启动 FixKey，或从 FixKey 发布页面重新安装适合您设备的软件包。您可以手动重新安装之前的版本；FixKey 绝不会自动降级。

## 故障排除和支持

如果纠正功能未启用，请打开**诊断和帮助**，查看状态和原因代码。重新检查权限，并尝试在其他应用程序的可编辑字段中使用。显示“正在等待可编辑字段”的状态表示无法安全识别当前字段。另请检查纠正功能是否已暂停，或该应用程序是否已被排除。

使用**打开日志文件夹**查看本地诊断日志，或使用**删除日志**将其移除。日志包含诊断结果和原因代码，而不包含输入内容。FixKey 最多保留七天的日志，日志总大小上限为 10 MiB。

如需帮助，请使用**诊断和帮助**中的 GitHub Issues 链接，或打开 [GitHub Issues](https://github.com/delinoio/apps/issues)。请提供 FixKey 版本、操作系统、受影响的应用程序和原因代码。请勿包含隐私文本或凭据。
