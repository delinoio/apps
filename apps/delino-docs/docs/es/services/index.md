# Servicios

- [Delcore](/es/services/delcore/): consulta el estado del tenant desde un servicio registrado.
- [DevBase](/es/services/devbase/): administra los usuarios finales de tus aplicaciones.
- [Git Tracker](/es/services/git-tracker/): realiza un seguimiento de las mediciones de los commits y las regresiones.
- [FixKey](/es/services/fixkey/): corrige palabras en coreano e inglés escritas con una distribución de teclado incorrecta.
- [DeliTools](/es/services/delitools/): traduce textos y extrae JSON de texto con API de pago.

Consulta [Primeros pasos](/es/guide/getting-started) para obtener una introducción al sitio de documentación.
