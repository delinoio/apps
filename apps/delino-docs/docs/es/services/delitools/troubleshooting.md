# Configuración y solución de problemas de DeliTools

Esta página te ayuda a configurar un cliente para DeliTools y a corregir errores. Para conocer las reglas de los campos, consulta la [referencia de la API](/es/services/delitools/api-reference).

## Configura tu cliente

- **URL base.** Usa la URL del servidor de la API de DeliTools que te proporcione el operador del servicio. Los procedimientos se encuentran en `/delitools.v1.DelitoolsService/Translate` y `/delitools.v1.DelitoolsService/Extract`.
- **Protocolo.** Usa un cliente Connect o envía JSON con `POST` y `Content-Type: application/json`. Los nombres de los campos JSON usan lowerCamelCase.
- **Credencial.** Envía `Authorization: Bearer <credential>`. Usa un token de inicio de sesión de Delino o una clave de API que empiece por `dlk_`. Guarda las claves en el código del servidor. DeliTools no admite llamadas desde navegadores.
- **Tenant.** Un token de inicio de sesión necesita `tenantId`. Una clave de API ya identifica su tenant; si también envías `tenantId`, debe coincidir.
- **Modelo.** Usa un identificador de modelo que permita el operador. La extracción usa un modelo fijo y no tiene un campo `model`.
- **Tiempos de espera.** Establece un tiempo de espera del cliente adecuado para tu solicitud más grande. Una llamada al proveedor puede tardar varios segundos y DeliTools puede reintentar los fallos transitorios, por lo que la llamada completa puede tardar más. Una solicitud que supere el tiempo de espera de ejecución del operador devuelve `ERROR_REASON_TIMEOUT`; si tu propio tiempo de espera cierra la llamada antes, DeliTools la trata como una cancelación.
- **Reintentos.** Reintenta cuando recibas `ERROR_REASON_RATE_LIMITED`, `ERROR_REASON_PROVIDER_FAILED`, `ERROR_REASON_DEPENDENCY_UNAVAILABLE` y `ERROR_REASON_TIMEOUT`, con espera exponencial y un pequeño retraso aleatorio. Cada reintento es una nueva ejecución que puede generar un cargo. Consulta [Facturación](/es/services/delitools/billing). No reintentes sin cambios las solicitudes que no superen la validación.

## Corrige un error

| Motivo                                | Qué hacer                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ERROR_REASON_INVALID_INPUT`          | Corrige la solicitud. Comprueba si hay cadenas vacías, las etiquetas de idioma, el ID del tenant, el modelo y si el esquema es JSON válido.                                                                                                                                                                                                   |
| `ERROR_REASON_UNAUTHENTICATED`        | Comprueba el token o la clave. Puede estar mal escrito, haber caducado, haberse revocado o pertenecer a un tenant eliminado. Crea una clave nueva si has perdido el secreto. Si todas las claves válidas fallan de repente, avisa al operador del servicio: una identidad de servicio mal configurada hace que las claves parezcan inválidas. |
| `ERROR_REASON_PERMISSION_DENIED`      | Comprueba que la clave conceda `translate` o `extract`, que el usuario siga teniendo permisos en el tenant y que cualquier `tenantId` que envíes corresponda al tenant de la clave.                                                                                                                                                           |
| `ERROR_REASON_BILLING_BLOCKED`        | Resuelve el problema de facturación en Delcore, como el saldo o la renovación, y vuelve a intentarlo.                                                                                                                                                                                                                                         |
| `ERROR_REASON_LIMIT_EXCEEDED`         | Envía menos datos: menos elementos, texto más corto o un esquema más pequeño. Divide los trabajos grandes en varias solicitudes.                                                                                                                                                                                                              |
| `ERROR_REASON_RATE_LIMITED`           | Reduce el ritmo y las solicitudes simultáneas, y vuelve a intentarlo tras una breve espera.                                                                                                                                                                                                                                                   |
| `ERROR_REASON_MODEL_UNAVAILABLE`      | Si el error es `invalid_argument`, el modelo no está permitido: elige otro. Si es `failed_precondition`, pide al operador que registre los precios del modelo.                                                                                                                                                                                |
| `ERROR_REASON_UNSUPPORTED_SCHEMA`     | Elimina las palabras clave que no pertenezcan al [subconjunto admitido](/es/services/delitools/api-reference). La raíz debe ser un esquema de objeto.                                                                                                                                                                                         |
| `ERROR_REASON_PROVIDER_FAILED`        | Espera y vuelve a intentarlo. Si persiste, contacta con el operador e incluye el ID de la solicitud.                                                                                                                                                                                                                                          |
| `ERROR_REASON_INVALID_OUTPUT`         | Vuelve a intentarlo una vez. Simplifica el esquema o la entrada si se repite. El intento genera un cargo.                                                                                                                                                                                                                                     |
| `ERROR_REASON_EXTRACTION_FAILED`      | El texto carece de información obligatoria. Proporciona los datos que faltan o haz que la propiedad sea opcional en tu esquema. El intento genera un cargo.                                                                                                                                                                                   |
| `ERROR_REASON_TIMEOUT`                | Envía solicitudes más pequeñas. Vuelve a intentarlo más tarde.                                                                                                                                                                                                                                                                                |
| `ERROR_REASON_CANCELED`               | Tu cliente cerró la conexión. Comprueba si se han agotado los tiempos de espera del cliente o si este se ha cerrado.                                                                                                                                                                                                                          |
| `ERROR_REASON_DEPENDENCY_UNAVAILABLE` | Vuelve a intentarlo más tarde. DeliTools rechaza el trabajo de pago cuando no puede comprobar la autorización.                                                                                                                                                                                                                                |

## Problemas habituales

- **Una clave funciona en una solicitud y falla en la siguiente.** Una clave que haya caducado, se haya revocado o pertenezca a un usuario que haya perdido los permisos deja de funcionar de inmediato. Compruébala con `ListApiKeys`.
- **Un error `resource_exhausted` sin motivo.** El cuerpo de tu solicitud supera el límite de tamaño global del operador. Envía menos datos.
- **Un resultado parece incorrecto.** Los modelos pueden cometer errores, y un resultado que siga tu esquema no es necesariamente correcto. Aclara las instrucciones de los campos `description` de tu esquema y comprueba los valores importantes.
- **Cargos inesperados.** Los intentos fallidos con consumo conocido y las solicitudes repetidas generan cargos. Consulta [Facturación](/es/services/delitools/billing).
- **El consumo aún no aparece.** El consumo llega a Delcore poco después de la llamada. Vuelve a comprobarlo más tarde.

## Solicita ayuda

Incluye el ID de la solicitud del cuerpo de la respuesta o del encabezado `X-Delitools-Request-Id`, el nombre del procedimiento, la hora y el motivo del error. No envíes tu clave de API, tu token de inicio de sesión ni los textos que hayas enviado.
