# DeliTools 요금 청구

DeliTools는 요청에 사용된 AI 토큰에 대해 테넌트에 요금을 청구합니다. Delcore는 사용량에 요율을 적용하고 잔액, 크레딧, 청구서를 관리합니다. 이 페이지에서는 사용량이 어떻게 요금으로 산정되는지 설명합니다.

## 측정 항목

- DeliTools는 각 시도에 대해 AI 제공업체가 보고하는 **입력 토큰** 및 **출력 토큰**의 총량을 읽습니다. 보고된 총량을 그대로 사용합니다.
- 보고된 총량에는 캐시된 토큰이나 추론 토큰이 이미 포함되어 있습니다. DeliTools는 이 부분을 다시 더하지 않으며, 별도의 캐시 할인이나 추론 할증 요금을 적용하지 않습니다.
- DeliTools는 입력 및 출력 사용량을 Delcore에 별도로 보고하며, Delcore는 각각의 가격으로 요금을 산정합니다.

## 가격

- 서비스 운영자는 Delcore에서 각 모델의 토큰 방향별(입력 및 출력) 가격을 설정합니다. 모델마다 가격이 다를 수 있습니다.
- 번역과 추출에는 동일한 가격이 적용됩니다. 추출은 항상 `openai/gpt-6-luna`를 사용하므로, 해당 모델의 입력 및 출력 가격으로 요금이 산정됩니다.
- 입력 및 출력 가격이 모두 등록되지 않은 모델은 실행할 수 없습니다. 요청은 `ERROR_REASON_MODEL_UNAVAILABLE`로 실패하며, 다른 모델로 대체되지 않습니다.
- 가격 변경은 변경 이후에 시작하는 실행에 적용됩니다. 이미 시작된 사용량에는 시작 시점의 가격이 유지됩니다.
- 포함 사용량, 잔액, 잔액 소진 후 계속 사용할 수 있는지 여부는 요금제에 따라 결정됩니다. Delcore에서 요금제와 청구서를 확인하세요.

## 요금이 부과되는 항목

- **사용량이 확인된 모든 시도에 요금이 부과됩니다.** 결과가 유효하지 않은 시도, 추출에 실패한 시도, 취소하기 전에 응답이 도착한 시도, 결과가 사용자에게 전달되지 않은 시도도 포함됩니다.
- **재시도는 별개의 시도입니다.** 일시적인 제공업체 장애(네트워크 오류 또는 HTTP 5xx나 429 응답)는 사용량을 반환하지 않으므로, DeliTools는 실패한 시도에 요금을 부과하지 않고 재시도합니다. 사용량이 확인된 제공업체의 완료된 응답은 시도 반복을 종료하며, 출력이 유효하지 않더라도 요금이 부과됩니다. DeliTools는 유효하지 않은 출력을 수정하기 위해 재시도하지 않기 때문입니다. 사용량이 없는 응답에는 요금이 부과되지 않습니다.
- **알 수 없는 사용량에는 요금이 부과되지 않습니다.** 제공업체가 사용 가능한 토큰 총량을 보고하지 않으면, DeliTools는 요금을 추정하지 않으며 나중에 사용량을 조회하지도 않습니다.
- **중단된 호출에는 요금이 부과되지 않습니다.** 제공업체 호출이 아직 실행 중일 때 취소하거나 실행 제한 시간이 경과하면, 사용량 보고가 도착하지 않으므로 제공업체가 이미 작업을 시작했더라도 요금이 부과되지 않습니다. 이는 알려진 제한 사항으로, DeliTools는 이 사용량을 나중에 조회하지 않습니다.
- **사용량은 반드시 기록되어야 합니다.** DeliTools는 응답하기 전에 모든 시도의 사용량을 저장합니다. 저장할 수 없으면 요청은 `ERROR_REASON_DEPENDENCY_UNAVAILABLE`로 실패하며 결과가 반환되지 않습니다.
- **거부된 요청에는 요금이 부과되지 않습니다.** 유효성 검사, 인증 또는 권한 부여에 실패하거나, 한도에 도달하거나, 지원되지 않는 스키마를 사용하는 요청은 AI 제공업체에 전달되지 않습니다.
- **모든 호출은 새로운 호출입니다.** DeliTools는 멱등성 키나 결과 재전송 기능을 제공하지 않습니다. 동일한 요청을 다시 보내면 다시 실행되고 요금도 다시 부과됩니다.

## 요금이 표시되는 시점

DeliTools는 응답하기 전에 각 시도의 사용량을 저장한 다음 Delcore에 보고합니다. 사용량 보고는 요청과 별도로 처리되므로, 호출 직후 잠시 뒤에 Delcore에 요금이 표시될 수 있습니다. Delcore를 사용할 수 없으면 DeliTools는 동일한 식별자로 계속 재시도하므로, 재시도로 인해 중복 요금이 발생하지 않습니다.

DeliTools가 전달하지 못한 사용량 기록은 생성된 지 30일 후에 삭제되며, 재시도로 이 기간이 연장되지는 않습니다. 해당 기간 내에 전달되지 않은 사용량에는 요금이 부과되지 않습니다. DeliTools는 이를 추정하지 않습니다.

사용량과 요금은 Delcore에서 확인할 수 있습니다. DeliTools 응답에는 이러한 정보가 포함되지 않습니다.

## 잔액 확인 및 초과 사용

Delcore는 각 요청 전과 각 재시도 전에 권한 및 결제 상태를 확인합니다. 호출을 위해 금액이나 토큰을 미리 확보하지는 않습니다. 비용은 호출이 완료된 후에만 알 수 있습니다. 따라서 여러 요청이 동시에 실행되면 남은 잔액이나 포함 사용량을 초과하여 사용할 수 있습니다. 잔액이 소진되거나 한도에 도달하면 Delcore는 이후 요청을 `ERROR_REASON_BILLING_BLOCKED`로 차단합니다.

Delcore에 연결할 수 없으면 DeliTools는 새로운 유료 요청을 실행하지 않고 거부합니다.

## 차단된 요청

`ERROR_REASON_BILLING_BLOCKED`는 Delcore가 테넌트의 유료 사용을 차단했다는 의미입니다. 일반적인 원인으로는 잔액 소진, 갱신 실패 또는 유료 기간 만료, 해결되지 않은 분쟁, 운영자에 의한 차단, 삭제 중인 테넌트 등이 있습니다. Delcore에서 원인을 해결하세요. 예를 들어 잔액을 충전하거나 구독을 갱신하세요. 유료 사용이 차단된 동안에도 테넌트 관리와 결제 복구 기능은 계속 사용할 수 있습니다.
